# ContrastCoach v4 UI/UX Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the v4 premium HTML mockup pixel-faithfully onto the existing ContrastCoach Flutter app, build 10 missing screens with real data, and ship all §4 wiring gaps.

**Architecture:** Existing 3-layer (domain pure-Dart / data Drift+Firebase+Gemini / presentation Flutter). ThemeExtension<AppColors> + ThemeController powers live accent recolor. New `journal_entries` Drift table + `settings` migration. Gemini Flash Lite backs the Coach with deterministic offline fallback.

**Tech Stack:** Flutter 3.24, Riverpod 2.6, Drift 2.20 + SQLCipher, Firebase, RevenueCat, `google_generative_ai`, `fl_chart`, `share_plus`, plus Jakarta Sans + JetBrains Mono.

## Global Constraints
- Exact v4 hex (Section 2.1 of spec); accents identical in light+dark
- Accents identical in light+dark; only ink/bg/card/line flip
- `--heat #FF6B35` etc verbatim from spec §2.1
- Spring curve `Cubic(0.22, 1, 0.36, 1)`; default 260ms
- `flutter analyze` clean + `flutter test` green after every task
- No hardcoded mock data — only static `assets/{protocols,challenges,reviews}.json` are intentional
- Key NOT committed — `--dart-define=GEMINI_API_KEY=<real>`
- Emoji map per spec §2.4 / spec §3.1 verbatim
- Don't touch: Play Store listing, store submission, real `google-services.json`
