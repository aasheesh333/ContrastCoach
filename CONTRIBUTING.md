# Contributing to ContrastCoach

Thank you for your interest in ContrastCoach! Currently this is a solo project in pre-development. The roadmap is documented in [`CONTRASTCOACH_MASTER_PLAN.md`](./CONTRASTCOACH_MASTER_PLAN.md).

## When contributions will be accepted

- **Pre-MVP (now):** Documentation fixes, research paper citations, design feedback via issues
- **Post-MVP (after v0.1 launch):** Code contributions, translations, beta testing
- **Post-revenue (after $5k MRR):** Formal contribution process with review board

## How to contribute now

1. **Open an issue** for any bug, feature, or research finding
2. **Use templates** provided in `.github/ISSUE_TEMPLATE/`
3. **Be specific** — vague issues get closed

## Code style (when code contributions open)

- Follow `very_good_analysis` lints (strict)
- Use `dart format` (enforced in CI)
- All public APIs documented with `dart doc`
- Widget tests required for new components
- Integration tests required for new flows

## Privacy is non-negotiable

Any contribution that:
- Sends health data to a server without explicit opt-in
- Tracks users across sessions without consent
- Adds advertising tracking
- Removes the local-first guarantee

...will be rejected. Privacy is a core product feature, not an afterthought.

## Community standards

- Be respectful, especially of biohacking beginners
- Cite sources for health claims
- No medical advice — refer users to professionals
- No affiliate spam
