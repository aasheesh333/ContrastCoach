## Design System Enforcement

All screens strictly follow:

- No chromatic colors (no blue, red, green, orange, yellow, purple, etc.)
- No gradients except monochrome tonal
- No images, illustrations, photos, or emojis
- All states via opacity, weight, or shape (not color)
- No marketing copy
- All buttons uppercase 14sp letter-spacing +0.1 for labels
- 24dp horizontal screen margins
- 56dp primary button height, 12dp corner radius
- Inter Tight for display + headlines, Inter for body, JetBrains Mono for timer

## Notes

- Active session screen is intentionally always dark (matches design intent — distraction-free, high contrast timer)
- All onboarding steps are skip-less (no skip button per master plan)
- Paywall has no countdown, no "limited time" copy, no pre-selected plan
- 88dp pause button matches Material 3 minimum touch target
- Goal grid uses 2x2 layout (4 goals: Recovery, Energy, Sleep, Immunity)
- Bottom nav has 3 items (Home, Insights, Profile) per Material 3
